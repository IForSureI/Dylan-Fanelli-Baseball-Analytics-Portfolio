MLB regular seasons 2024–2026: Statcast pitches

Does a pitch wear out?

In three seasons of data, yes, and it's specific to the pitch type. The more of a pitch a hitter has seen from this pitcher today, the less he misses it. Seeing more pitches of other types doesn't do the same. Changeups and splitters wear out fastest. Part of the effect carries to the next same-handed pitcher who throws the same pitch.

What changes

Contact, not discipline

Per earlier same-type pitch, against the same pitch type in the same count and spot.

Hitters chase familiar fastballs and breaking balls more, not less, and still miss less. They're making contact, not laying off. Each earlier changeup goes with 11.6 more points of xwOBA on contact on the next one.

It follows the hitter to the next pitcher

Whiff-rate change per pitch of the same type the hitter saw from a different pitcher earlier today.

A changeup reliever who follows a same-handed changeup starter starts with a partly used pitch. The other-hand carryover is smaller and not significant, and so is the gap between hands, so hand is a lean, not a rule. A splitter seen earlier goes with a weaker changeup almost as much.

What doesn't matter

You can't grade a pitch on it

  • One season can't measure it pitch by pitch. A single pitch's season slope carries 3–4 points of noise against effects of 1–2. The year-to-year correlation is borderline for fastballs (0.10, SE 0.04) and absent for secondaries.
  • Fastball stuff is the one trait that predicts it. Better fastballs lose more per look.
  • No sign that release tells speed it up. This matches the Edge Board's result that tells haven't cost whiffs.
  • No sign that usage, movement separation or a secondary's stuff changes it. Firmer changeups looked like they held up better (p = 0.02), but that doesn't survive correction for 13 tests (q = 0.14).

How sure

It holds across specifications

Cutters are the weak group. They're significant pooled (p = 0.03) and in 2024, but not in 2025 or 2026. The placebo is the same pitch type thrown in the hitter's later plate appearances, which can't affect the current pitch. Its estimate is large and positive (+2 to +3 points): pitchers go back to what's working. The same selection could push the main estimates toward zero. Holding future pitches fixed changes them very little, so read the main estimates as probably not overstated.

Method

How it was measured

Grain: one row per pitch. Exposure counts every pitch the same pitcher threw the same batter before the current pitch, in three windows: earlier plate appearances today, earlier in this plate appearance, and earlier games this season. Each window is split into same type versus other types. Writing each pair as same + same + other makes the coefficient on same the contrast: one earlier pitch having been this type instead of another.

Model: associations from a linear probability model for whiffs and chases, linear for run value and xwOBA on contact. Two sets of fixed effects are absorbed by alternating projections: pitcher × pitch type × season, and batter × pitch group × season. Controls cover count, times through, pitch count and its square, handedness, the pitch's velocity, rise, run and spin, and location. Standard errors are clustered by pitcher.

Limits: this is observational. Location and count are partly the pitcher's response, so the main estimate holds them fixed; letting them vary gives larger effects for every group except cutters. The data can't separate recognition from timing.
