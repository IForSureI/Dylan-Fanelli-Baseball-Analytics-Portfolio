How it works

Method, and what would make it wrong

Expected whiffs (stuff)

A gradient-boosted model predicts whether a swing misses from the pitch's physics alone: velocity, rise, run, spin, extension, release, arm angle, the gap to the pitcher's own fastball, and batter hand. It never sees location, count or sequence. Every pitcher's numbers come from a model that never saw him (5 folds grouped by pitcher). The gap is actual whiff% minus expected whiff%.

Release tells

Within each game, release height, side, extension and arm angle are measured relative to that game's fastballs, which removes ballpark camera differences. A logistic model tries to tell each secondary pitch from the fastball using release alone, scored out of sample by game. 0.5 means the release says nothing; 1.0 means it gives the pitch away. Hawk-Eye measures differences a hitter may never see.

Hidden changes

For each pitch and metric, the game where its average shifted most, kept only if the shift is large, statistically strong after trying every split, and holds in later games. A change shared by all of a pitcher's pitches is labeled as delivery or measurement. Changes where the new shape looks like another of his pitches are labeled as possible relabels and left off the list. The verdict uses expected whiffs before and after, which shows up long before actual whiffs settle.

2027 projection

Next-season whiff% from this season's actual, last season's actual and this season's expected whiff%, with weights fit on 2024 and 2025 predicting 2026. Pitches without a prior season use a one-season blend. It projects whiff rate only, not run prevention, health or role.
